# Bajaj Finance Product Portfolio Demo

Responsive product portfolio showcase built with HTML5, CSS3 and vanilla JavaScript.

## Six product categories
1. Personal Loan
2. Home Loan
3. Business Loan
4. Fixed Deposit
5. EMI Network Card
6. Insurance

## Features
- Sticky responsive navigation and mobile menu
- Smooth anchor scrolling
- Six product cards with CSS artwork
- Product category filters
- Product detail modal
- Scroll reveal animations using IntersectionObserver
- Hover transitions and animated hero illustration
- Back-to-top button
- Keyboard support and reduced-motion support
